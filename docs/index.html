textrep 1.2.0

Lightweight text analysis for Python projects.

TextRep turns raw text and document files into useful counts, frequency tables, readability metrics, and structured analysis objects without pulling in a heavy NLP stack.

Start using TextRep View functions 
import textrep as tr

text = "Hello world. TextRep analyzes text."

result = tr.analyze(text)

print(result.stats.word_count)
print(result.readability.reading_time_minutes)
print(result.word_frequency)

Use Cases

TextRep is useful when you need dependable text measurements more than machine learning, semantic search, or language modeling.

Content tools

Editorial dashboards

Measure word count, sentence count, average word length, reading time, and repeated terms before publishing.

Automation

Document checks

Load text-like files from disk and validate length, density, symbols, or repeated words in scripts and CI tasks.

Learning

Text analysis basics

Teach tokenization, counting, frequency analysis, and simple readability concepts through a readable Python API.

Data prep

Corpus profiling

Generate quick statistics for samples before feeding documents into indexing, reporting, or analytics pipelines.

CLI workflows

File reports

Use the bundled command-line entry point or legacy analyzer to inspect plain text files quickly.

Apps

Feature extraction

Add typed text metrics to web apps, internal tools, notebooks, and lightweight backend services.

Quick Start

Install TextRep, import it, and call the function that matches the result you need.

pip install textrep

# Optional document loaders
pip install textrep[pdf]
pip install textrep[docx]
pip install textrep[all]
import textrep as tr

text = "Hello world. Hello TextRep."

tr.word_count(text)
tr.readability(text)
tr.top_words(text, n=5)
tr.analyze(text)

API Styles

The functional API is the source of truth. The object APIs keep text, file metadata, and reusable methods together.

Functional API

Use textrep.word_count(text), textrep.stats(text), or textrep.analyze(text) when you already have a string.

Document API

Create Document(text) when repeated analysis should stay attached to one piece of text and optional metadata.

File API

Call load(path) to read a supported file and receive a Document with source metadata.

Legacy API

TextAnalyzer(path) remains available for older v1-style file analysis code.

Functions

These are the public functions exported from textrep.

analyze(text)

Returns one AnalysisResult containing core stats, readability, character frequency, word frequency, and metadata.

stats(text)

Returns TextStats with word, character, letter, digit, space, symbol, unique word, and average word length metrics.

readability(text)

Returns ReadabilityStats with sentence count, average sentence length, and reading time in minutes.

word_count(text)

Counts lowercase word tokens using TextRep tokenization.

character_count(text)

Counts every character in the input string, including whitespace and punctuation.

letter_count(text)

Counts alphabetic characters only.

digit_count(text)

Counts numeric digit characters.

space_count(text)

Counts whitespace characters.

symbol_count(text)

Counts characters that are not alphanumeric and not whitespace.

unique_word_count(text)

Counts distinct lowercase word tokens.

average_word_length(text)

Returns the average word-token length rounded to two decimals.

longest_word(text)

Returns the longest token, or an empty string when no words are found.

shortest_word(text)

Returns the shortest token, or an empty string when no words are found.

sentence_count(text)

Counts non-empty sentence-like spans separated by punctuation such as periods, exclamation marks, and question marks.

reading_time(text, words_per_minute=200)

Estimates minutes to read the text. It raises ValueError if words per minute is zero or negative.

character_frequency(text)

Returns a case-insensitive character frequency dictionary sorted by descending count.

word_frequency(text)

Returns a case-insensitive word frequency dictionary sorted by descending count.

top_words(text, n=10)

Returns the n most common words as (word, count) tuples.

load(path)

Loads a supported file from disk and returns a Document.

File Loading

TextRep can extract text from common document formats. Plain text, Markdown, and HTML work with the standard library. PDF and DOCX use optional dependencies. 

import textrep as tr

doc = tr.load("article.md")

print(doc.metadata.file_name)
print(doc.word_count())
print(doc.to_dict())
.txt .md .markdown .html .htm .pdf .docx

Install textrep[pdf] for PDF extraction, textrep[docx] for Word documents, or textrep[all] for both optional loaders.

Result Objects

TextRep returns dataclasses so callers can use typed attributes instead of loosely shaped dictionaries.

TextStats

Includes word_count, character_count, letter_count, digit_count, space_count, symbol_count, unique_word_count, and average_word_length.

ReadabilityStats

Includes sentence_count, average_sentence_length, and reading_time_minutes.

DocumentMetadata

Stores source, file_name, and extension when a document is loaded from disk.

AnalysisResult

Combines TextStats, ReadabilityStats, frequency dictionaries, and metadata into one complete result.

Errors and Compatibility

TextRep exposes focused exception classes and keeps a legacy analyzer for older code.

TextRepError

Base class for TextRep-specific exceptions.

UnsupportedFileTypeError

Raised when load(path) receives an unsupported file extension.

MissingDependencyError

Raised when a file loader needs an optional dependency that is not installed.

TextAnalyzer(path)

Backward-compatible file analyzer that returns the legacy AnalysisReport shape.
