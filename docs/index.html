textrep v1.2.0 • Lightweight Python Library

Lightweight text analysis for Python projects.

TextRep turns raw text and document files into precise counts, word frequency tables, readability metrics, and typed analysis objects without pulling in a heavy NLP stack.

$ pip install textrep

example.py 
import textrep as tr

# Analyze text directly
text = "Hello world. TextRep analyzes text fast."
result = tr.analyze(text)

print(result.stats.word_count)  # 6
print(result.readability.reading_time_minutes)  # 0.03
print(result.word_frequency)  # {'textrep': 1, 'analyzes': 1...}

Getting Started

Quick Start

Install TextRep via pip, import the package, and call the function that matches your required analysis level.

1. Installation Options 
# Core installation (Zero external dependencies)
pip install textrep

# Optional document loaders
pip install textrep[pdf]    # PDF support via pypdf
pip install textrep[docx]   # Word docx support
pip install textrep[all]    # Install all loaders
2. Basic Usage 
import textrep as tr

text = "Hello world. Hello TextRep."

# Convenient standalone functions
tr.word_count(text)           # 4
tr.readability(text)          # ReadabilityStats
tr.top_words(text, n=5)       # [('hello', 2), ('world', 1)...]
tr.analyze(text)             # Full AnalysisResult
Architecture

API Styles

Choose the API paradigm that best matches your project structure. The functional API is the source of truth, while object APIs keep documents and metadata attached.

Functional API

Use textrep.word_count(text), textrep.stats(text), or textrep.analyze(text) when working with raw in-memory strings.

Document API

Instantiate Document(text) when repeated profiling should remain attached to an object instance with custom metadata.

File API

Call load(path) to auto-detect and parse document formats from disk, returning a Document object with file metadata.

Legacy API

TextAnalyzer(path) remains supported for full backward-compatibility with v1-style file analysis codebases.

Functions API

Explore the complete suite of public functions exported directly from the top-level textrep module.

analyze(text)

Returns a unified AnalysisResult object containing core stats, readability metrics, character/word frequencies, and metadata.

Core Stats
stats(text)

Returns a TextStats dataclass containing word count, character count, letter/digit/space/symbol breakdown, and unique word counts.

Core Stats
readability(text)

Returns a ReadabilityStats dataclass with sentence count, average sentence length, and estimated reading time in minutes.

Readability
word_count(text)

Counts word tokens using TextRep tokenization rules.

Core Stats
character_count(text)

Counts every single character in the string, including whitespace, symbols, and punctuation marks.

Core Stats
letter_count(text)

Counts alphabetic letters (A-Z, a-z) in the input string.

Core Stats
digit_count(text)

Counts numeric digit characters (0-9).

Core Stats
space_count(text)

Counts whitespace characters including spaces, tabs, and newlines.

Core Stats
symbol_count(text)

Counts non-alphanumeric and non-whitespace punctuation characters.

Core Stats
unique_word_count(text)

Counts unique, distinct lowercase word tokens in the text corpus.

Core Stats

Returns average word token length rounded to two decimal places.

Core Stats

Returns the longest word token found in the text, or an empty string if no words exist.

Core Stats

Returns the shortest word token in the text string.

Core Stats

I/O Loaders

File Extraction

TextRep extracts clean text from common document types. Plain text, Markdown, and HTML work out of the box. PDF and DOCX use optional extras.

file_loader.py 
import textrep as tr

# Load Markdown or PDF seamlessly
doc = tr.load("article.md")

print(doc.metadata.file_name)  # "article.md"
print(doc.word_count())         # 482
print(doc.to_dict())            # Full serializable dict

Datatypes

Result Objects

TextRep returns typed Python dataclasses, providing autocomplete support and IDE type checking instead of loose dictionaries.

TextStats

Contains word_count, character_count, letter_count, digit_count, space_count, symbol_count, unique_word_count, and average_word_length.

ReadabilityStats

Contains sentence_count, average_sentence_length, and reading_time_minutes.

DocumentMetadata

Stores source path, file_name, and file extension when a document is parsed from local disk storage.

AnalysisResult

Combines TextStats, ReadabilityStats, frequency dictionaries, and metadata into a complete result object.

Exceptions

Errors & Legacy Support

TextRep provides descriptive, typed exceptions for file handling and retains backward compatibility for older v1 integrations.

TextRepError

Base class for all TextRep-specific exceptions in Python application code.

Base Exception
UnsupportedFileTypeError

Raised when load(path) is passed an unrecognized or unsupported document extension.

File Exception
MissingDependencyError

Raised when a file loader requires an uninstalled optional extra (e.g. pypdf for PDF files).

Dependency Exception
TextAnalyzer(path)

Backward-compatible file analyzer returning the legacy AnalysisReport structure for v1 migration path.
